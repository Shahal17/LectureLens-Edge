# Archived Challenge Material

This folder preserves the original application and presentation material for
project history.

These files are not the primary product documentation:

- `SUBMISSION_PROPOSAL.md`
- `SUBMISSION_FORM_ANSWERS.md`
- `PITCH_SCRIPT.md`
- `DEMO_SCRIPT.md`
- `JUDGING_MATRIX.md`
- `submission-cover.svg`

Current product direction, setup, contribution guidance, and technical status
are maintained in the repository root and the main `docs/` folder.

Claims in archived files may describe planned hardware integration. Use the
current [README](../../README.md) and
[Snapdragon deployment plan](../SNAPDRAGON_DEPLOYMENT.md) when evaluating what
is implemented today.
